## Anomalies corrigées

- **Priorités non rechargées** : les valeurs de priorité sauvegardées n’étaient pas correctement reconnues au redémarrage. Leur lecture a été corrigée.
- **Fichier de données invalide** : l’application pouvait continuer après une erreur de chargement. Elle interrompt maintenant son démarrage lorsque le fichier est illisible ou mal formé.

## Anomalie connue non corrigée

- **Tabulation dans un titre** : un titre contenant une tabulation est accepté, mais la tabulation sert aussi à séparer les champs dans le fichier de données. Après sauvegarde, le fichier risque donc d’être considéré comme mal formé au prochain démarrage.
